About this data

These are the applications and categories used by UniFi Network for traffic identification and traffic rules. When you create a Traffic Rule to block or rate-limit a category like "Online Games", these are the specific applications included in that category.

Data is extracted from UniFi Network firmware. Version shown above.

How App IDs Work

UniFi uses compound IDs that encode the category: id = (category << 16) + app. For example, an app with ID 65538 belongs to category 1 (65538 >> 16 = 1) with app index 2 (65538 & 0xFFFF = 2).

Category 0 apps have simple low-numbered IDs since 0 << 16 = 0.
